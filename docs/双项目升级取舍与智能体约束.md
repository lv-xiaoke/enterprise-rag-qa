# 两个项目的升级核心目标

项目一突出 Agent 能力，项目二突出全栈工程与上线能力。以下是目标效果，已有能力保留，只补实际缺口。

## 项目一：LangGraph 智能体业务助手

**目标：让 AI 能正确调用业务工具，可靠地完成多步骤任务。**

- 能理解用户需求，选择制度查询、员工数据查询、周报生成等工具；缺少信息时先追问。
- 工具只访问当前用户有权查看的数据，修改员工 ID 或会话 ID 不能越权。
- 支持连续追问和会话恢复，不同用户、不同会话互不干扰。
- 能展示工具执行过程；超时或失败时明确说明，不编造执行成功，也不无限重试。
- 用固定案例验证工具选择、参数、权限、上下文和异常处理是否正确。

## 项目二：企业知识库 AI 全栈应用

**目标：把知识库问答做成可实际使用、可维护、可云端部署的 Web 产品。**

- 用户能注册登录、管理私有知识库、上传 PDF、流式问答、查看来源和恢复历史。
- 文档支持重复检测、更新和失败重试；上传后后台处理，页面可查看状态，旧版与新版制度不会混用。
- 回答有资料依据，无证据时拒答；通过固定问题评测发现并改进遗漏、错误和追问问题。
- 出现上传或问答故障时，能通过日志定位原因；服务重启后数据保留，处理状态能够恢复。
- 完成真实云端部署，具备 HTTPS、自动检查、调用限制、备份恢复和明确的版本更新方式。

## 两个项目的取舍

项目一保留 Streamlit，重点做 Agent 可靠性；项目二保留 React，重点做产品与工程交付。暂不合并项目，不在项目二重复建设 Agent，也不为堆技术引入多智能体、微服务等额外架构。
