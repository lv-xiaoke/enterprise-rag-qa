# 五分钟演示脚本

准备：按 README 完成迁移和初始化，设置自己的演示密码与模型 Key；用两个独立浏览器配置登录 admin、E1001/E1002。使用 `data/enterprise` 的制度文本上传，普通账号不会显示管理入口。未配置模型时可运行 Playwright 验收替身，演示时必须说明模型替身的范围。

1. 管理员上传 `hr_leave_policy.txt`，看到等待/处理完成。说明无文本 PDF 与 UTF-8 错误会显示失败，不自动替换有效旧版。
2. E1001 提问“请两天假找谁审批”，展示工具状态、流式答案与引用原文。随后追问“病假证明呢”，展示同会话记忆和来源。
3. 管理员更新同一文档，普通员工新问使用新版本；停用后不再检索它，历史引用仍显示历史版本。
4. E1001 查询“我的报销状态”，说明员工记录是模拟数据；尝试“查 E1002 的年假”，解释工具硬性权限校验。
5. 生成本周周报，点击“编辑并保存为周报”，修改标题正文后保存，刷新并重新登录读取。
6. 换 E1002，展示历史与周报列表隔离；直接请求 E1001 的资源返回 404。停止一个生成中的回答，说明 cancelled 与 interrupted 的区别。

结束时展示 `docs/verification-v1.md` 的实际测试证据。若模型断网或限流，展示 failed 状态和错误提示；不能临时把失败当成已完成。
